# GitLab / `glab` local files

- **`hamgit-token`** — create this file yourself (never commit it). Personal access token with `api` (and whatever your host requires for project listing). Used only for `glab api` discovery; clone/push use SSH.

```bash
printf '%s' 'YOUR_TOKEN' > glab/hamgit-token
chmod 600 glab/hamgit-token
```

- **`repos.txt`** — generated by the discovery phase into this directory. It is gitignored.
