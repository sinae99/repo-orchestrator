# glab/

Runtime files used by the discovery phase.
## `token`

Personal access token with `api` scope for your GitLab instance. Used **only** for `glab api` calls during discovery. Git operations (clone, push) use SSH.

```bash
printf '%s' 'glpat-xxxxxxxxxxxx' > glab/token
chmod 600 glab/token
```

Then authenticate the CLI:

```bash
cat glab/token | glab auth login --hostname gitlab.com --stdin
```

## `repos.txt`

Generated by the discovery phase — one SSH clone URL per line. Re-created on every discovery run. Do not edit by hand; edit `gitlab.repo_filter` in config instead.
